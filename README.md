# 🚀 Portfolio-V1.0

This is the first version of my personal portfolio, built with a focus on **experimental design** and hands-on styling.

---

### 💡 Design Philosophy

* **Organic Development:** This project was built without a pre-defined UI design (like Figma). I adopted a "trial and error" approach, refining each element’s aesthetics and responsiveness directly through code until achieving a polished look.
* **AI-Assisted Creativity:** The concept for the **"Contact Me"** section was sparked by creative inspiration from **Gemini AI**, which helped bridge the gap between functionality and design.
